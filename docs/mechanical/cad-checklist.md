# CAD Checklist

Go through this list before calling a design finished. See also the [CAD Guidelines](./cad-guidelines).

## Belts

- [ ] Check centre to centre distance
- [ ] Check that belt is available

## Gears

- [ ] Check centre to centre distance
- [ ] Check that gears are available

## General

- [ ] All features and sketches are named
- [ ] All parts are named
- [ ] All sketches are fully constrained
- [ ] No errors are present (red text)
- [ ] No warnings are present
- [ ] All parts have a material assigned, or a mass override
- [ ] Bolts/nuts/rivets are included in the assembly where significant
