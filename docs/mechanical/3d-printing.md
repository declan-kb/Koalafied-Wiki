This document might eventually be nicely organised to describe our 3D printing capability, but for the moment it is a dumping ground for things I (Nick) want to remember.

## Standard Screw Sizes

| Screw | Clearance | Bite | Head | Head Depth |
|-------|-----------|------|------|------------|
| Bunnings 6g Self Tapping Metal Screws - 12, 15, 25mm | 3.8mm | 2.8mm<br>3.0mm | 7mm | 2.5mm |
| Bunnings 4g Self Tapping Metal Screws - 9mm | 3.5mm | 2.5mm | 5.5mm | 2mm |
| M2 x 8mm Self Tapping | 2.2mm | 1.8mm | 3.5mm | |
| M1.7 x 6mm Self Tapping | 1.8mm | 1.5mm | 3.5mm | |
| M1 x 4mm Self Tapping | | | | |
| M3 bolt (torx) | 3.2mm | | 5.5mm | 2.2mm |
| M4 bolt pan | 4.3mm* | | 7.5mm | 2.5mm |

Clearance should allow the screw to turn in the hole but be a tight fit. This values will work for holes printed vertically. Hole printed horizontally with come out a little smaller.

Bite is the size of hole for the screw to screw into and grip. For bite use the larger size if the surrounding material is not thick or strong
