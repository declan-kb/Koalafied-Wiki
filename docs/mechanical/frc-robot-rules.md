# FRC Robot Rules Basics

The robot rules are in the **Robot Construction** section of the [Game Manual](https://www.firstinspires.org/resource-library/frc/competition-manual-qa-system). The types of rules stay the same each year but the numbers change, so check the current manual before starting CAD.

## What to Check Each Year

- **Weight** - maximum robot weight, excluding bumpers and battery
- **Robot perimeter** - maximum length around the robot's fixed frame
- **Starting configuration** - the robot must fit inside the perimeter and under a height limit at the start of a match
- **Extension** - how far mechanisms can reach past the perimeter, and how tall the robot can get, during a match
- **Bumpers** - coverage, construction, height, colours and team numbers. These change often.
- **Other** - part cost limit, allowed motors, safety, and what can be made before kickoff
